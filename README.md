# Answering Hard Questions

[![Built with Starlight](https://astro.badg.es/v2/built-with-starlight/tiny.svg)](https://starlight.astro.build/)

A small, growing portfolio of long-form research syntheses. Each entry takes a hard question, surveys the best available evidence, and lays out what it does and does not support — with citations throughout.

**🔗 Live site: https://answering-hard-questions.vercel.app**

## What this is

A structured, citation-backed synthesis rather than a blog. Every substantive claim links to a primary or authoritative source (academic papers, OECD/IMF/UN reports, agency pages, IRS 990 filings). The work is deliberately opinionated and invites readers to follow the citations and form their own judgment.

The first paper — **"How do we reduce global inequality?"** — runs through five sections:

1. **Current State** — how concentrated wealth is today, how it's measured, how it converts into political power, and whether it's even a problem worth acting on.
2. **Interventions** — specific policy and institutional levers (progressive taxation, antitrust, financial regulation, labor power, predistribution, democratic reform, global tax coordination) and the evidence on each.
3. **Synthesis** — the most promising multipronged strategy, its prioritization, political feasibility, and risks/tradeoffs.
4. **Organizations** — research institutes, advocacy campaigns, international institutions, and grassroots movements pushing these levers.
5. **Career Options** — concrete roles inside those organizations and how to qualify for them.

## How this research was produced

This research was produced with [Claude Code](https://claude.com/claude-code) (Anthropic's AI agent tool) and **reviewed, fact-checked, and edited by the author, who is responsible for all content.** Citations were independently verified — confirming each source exists, says what it is cited as saying, and resolves to a working link. The model is a tool in the workflow, not an author, and is not cited as a source. Full statement: [/about](https://answering-hard-questions.vercel.app/about/).

## Tech stack

Built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/). Content lives as MDX in `src/content/docs/`, one directory per section; the sidebar is autogenerated and ordered by each page's `sidebar.order` front matter.

## Local development

```bash
npm install
npm run dev      # local dev server at http://localhost:4321
npm run build    # production build to ./dist/
npm run preview  # preview the production build locally
npm run publish -- "message"   # commit + push (deploys via Vercel)
```

Requires Node ≥ 22.12 (Astro 6). Content-editing workflow and conventions: [EDITING.md](./EDITING.md). Starlight template reference: [STARLIGHT.md](./STARLIGHT.md).

## Deployment

Deployed to [Vercel](https://vercel.com), git-connected: every push to `main` triggers a production build; pull requests get preview URLs. The site is served at the domain root (no base path).
