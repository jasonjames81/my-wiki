# Most Promising Interventions to Reduce Global Inequality

[![Built with Starlight](https://astro.badg.es/v2/built-with-starlight/tiny.svg)](https://starlight.astro.build/)

A research wiki surveying interventions to reduce the global concentration of wealth and power — the evidence behind each, the organizations advancing them, and the careers that build them.

**🔗 Live site: https://jasonjames81.github.io/my-wiki/**

## What this is

A structured, citation-backed synthesis rather than a blog. Every substantive claim — top-share figures, tax elasticities, campaign outcomes, organizational facts, compensation ranges — links to a primary or authoritative source (academic papers, OECD/IMF/UN reports, agency pages, IRS 990 filings). The synthesis is deliberately opinionated: it ranks interventions by a combination of effect size, political tractability, and reversibility, and invites readers to follow the citations and form their own judgment.

## Sections

1. **Current State** — how concentrated wealth is today, how it's measured, and how it converts into political power.
2. **Interventions** — specific policy and institutional levers (progressive taxation, antitrust, financial regulation, labor power, predistribution, democratic reform, global tax coordination) and the evidence on each.
3. **Synthesis** — the most promising multipronged strategy, its prioritization, political feasibility, and risks/tradeoffs.
4. **Organizations** — research institutes, advocacy campaigns, international institutions, and grassroots movements actively pushing these levers.
5. **Career Options** — concrete roles inside those organizations and how to qualify for them.

## Tech stack

Built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/). Content lives as MDX in `src/content/docs/`, organized into one directory per section; the sidebar is autogenerated from those directories.

## Local development

```bash
npm install
npm run dev      # local dev server at localhost:4321/my-wiki/
npm run build    # production build to ./dist/
npm run preview  # preview the production build locally
```

Requires Node ≥ 22.12 (Astro 6). Full template/command reference in [STARLIGHT.md](./STARLIGHT.md).

## Deployment

Deployed to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`). Every push to `main` rebuilds and redeploys. Because it's a project site served under a subpath, `astro.config.mjs` sets `base: '/my-wiki'`, and internal links in content are written with that prefix.
